## ---

**1\. 情境描述**

---

當運動員在比賽或訓練中受傷時，復健過程通常涵蓋兩個階段：先至醫院診斷，再轉往民間康復中心進行長期的復健與功能訓練。然而，兩者間因醫療與復健系統不互通，康復中心的治療師往往無法取得完整的醫療資訊，只能依賴患者模糊的「口頭轉述」，或是資訊極為有限的診斷證明書與影本。在缺乏受傷精確位置、損傷分級、用藥狀況及醫師特定醫囑的情況下，治療師只能憑經驗從頭評估。這不僅大幅增加時間與溝通成本，更可能因資訊落差做出不當的訓練安排，進而引發二次傷害的風險。

## **2\. 情境目標**

---

為了解決現行運動損傷復健中的雙向資訊黑洞，我們建立了一個以 FHIR 為核心的「運動損傷復健資訊互通平台」。透過此平台，醫師在完成診斷後，可將詳細的結構化資料即時上傳；康復中心的治療師經患者授權後，即可精準掌握傷情並擬定復健計畫，同時將每次訓練進度即時回傳。這不僅能實現「診斷 ➔ 運動處方 ➔ 復健執行 ➔ 居家追蹤 ➔ 回診評估」的雙向資料閉環，大幅降低二次傷害風險，也因採用 FHIR 標準，具備跨機構與整合穿戴裝置的高擴充性。

## **3\. 需求分析**

---

| 系統角色 / 面向 | 功能模組 | 詳細功能描述   |
| :---- | :---- | :---- |
| **通用 / 基礎架構** | **資料標準化** | 不同單位（醫院、康復中心）之系統皆能讀取與解析符合 FHIR 國際標準格式的資料。 |
| **患者（運動員）** | **基本資料管理** | 建立與查詢個人基本資訊（姓名、生日、性別、聯絡方式、從事運動項目）。 |
|  | **歷程查詢** | 患者可隨時透過系統查看個人的完整診斷報告與復健訓練進度。 |
|  | **隱私授權** | 提供授權機制，由患者同意後開放康復中心或特定治療師讀取病歷。 |
| **門診醫師** | **診斷資料登錄** | 填寫並上傳完整的結構化診斷說明（受傷部位、損傷類型與分級、診斷日期）。 |
|  | **影像報告整合** | 附上 X 光、MRI 等影像檢查紀錄與專業報告結論。 |
|  | **醫囑與禁忌設定** | 填寫復健醫囑及禁忌事項（例如：週內禁止負重、避免關節旋轉動作）。 |
|  | **回診追蹤檢視** | 回診時可調閱康復中心回傳的歷次復健紀錄與功能量測數據。 |
| **康復中心治療師** | **診斷資訊調閱** | 經授權後，直接讀取完整且結構化的醫師診斷、影像結論及禁忌醫囑。 |
|  | **復健計畫擬定** | 依據醫師診斷與醫囑，建立個人化復健計畫（包含短期/長期目標、復健週期與訓練項目）。 |
|  | **歷次復健紀錄** | 記錄每次復健的客觀量測數據與進度（如：關節活動度 ROM、疼痛指數 VAS、肌力等級）。 |

## **4\. 工作流程**

1. ---

   **受傷就醫**：運動員到醫院掛號，系統建立或查詢患者基本資料（Patient），並產生一筆就診紀錄（Encounter）。  
2. **檢查與診斷**：醫師安排 X 光／MRI，影像檢查紀錄以 ImagingStudy 建立；醫師判讀後產出診斷報告（DiagnosticReport），並將確定的傷病以 Condition 記錄（例：左膝前十字韌帶二級撕裂）。  
3. **開立運動處方箋**：醫師在系統中開立「復健/運動處方箋」（ServiceRequest），明確設定復健方向、強度指引與禁忌動作（如：六週內禁止負重深蹲）。  
4. **患者授權**：患者到康復中心報到，同意授權該中心讀取自己的診斷資料。  
5. **治療師讀取診斷**：治療師從平台（HAPI FHIR Server）查詢該患者的 Condition、DiagnosticReport、ServiceRequest，5 分鐘內完整掌握傷情，不必再靠患者轉述。  
6. **制定復健計畫**：治療師依據診斷資料建立復健計畫（CarePlan），設定階段目標（消腫止痛 → 恢復活動度 → 肌力重建 → 回場訓練）。  
7. **執行與記錄**：每次復健療程記錄為 Procedure，並將量測數據（膝關節屈曲角度、疼痛 VAS 分數、大腿圍度）以 Observation 上傳。  
8. **回診追蹤**：患者回醫院複診時，醫師直接在系統看到所有復健紀錄與量測趨勢，據此調整醫囑；資料形成完整閉環。

## **5\. 系統使用角色和權限**

### ---

**5.1 系統角色**

| 系統角色 | 主要權限與職責 | 對應 FHIR 資源 (FHIR Resources)   |
| :---- | :---- | :---- |
| **患者（運動員）** *Patient* | 提供並維護個人基本資料 管理個人醫療資料的調閱授權（同意康復中心讀取） 隨時查看自身的診斷報告、影像結果與歷次復健進度 | Patient Consent |
| **醫師 (骨科／復健科)** *Practitioner* | 登錄與確定傷勢診斷 開立醫囑、禁忌事項與復健轉介建議 回診追蹤時調閱康復中心回傳的復健數據與趨勢圖表 | Condition DiagnosticReport ServiceRequest |
| **放射師／檢查人員** *Radiographer / Staff* | 執行 X 光、MRI 等醫學影像檢查 登錄與上傳影像檢查紀錄與 DICOM/PACS 連結資訊 | ImagingStudy |
| **康復中心治療師 (物理治療師／運動防護員)** *Therapist* | 經授權後調閱完整診斷、影像結論與醫師醫囑 制定與調整個人化復健計畫與階段目標 記錄每次復健項目與客觀量測數據（ROM、VAS、肌力） | CarePlan Procedure Observation |

### **5.2 系統角色權限**

**權限代碼說明：** C (Create 建立) / R (Read 讀取) / U (Update 更新) / A (Authorize 授權管控)

| FHIR Resource | 患者 (Patient) | 醫師 (Practitioner) | 放射師 / 檢查人員 | 治療師 (Therapist) | 權限說明與安全控管   |
| :---- | :---- | :---- | :---- | :---- | :---- |
| **Patient** *(基本資料)* | **R / U** | R | R | R | 患者可維護與更新個人聯絡資訊與從事運動項目。 |
| **Consent** *(隱私授權)* | **C / R / A** | R | \- | R | **僅患者本人有權授權或撤銷**康復中心對其病歷的調閱權限。 |
| **Condition** *(傷病診斷)* | R | **C / R / U** | \- | R *(需授權)* | 僅門診醫師有權開立、確定與更新傷病診斷結果。 |
| **DiagnosticReport** *(診斷報告)* | R | **C / R / U** | \- | R *(需授權)* | 醫師判讀與撰寫之專業檢查報告及結論。 |
| **ImagingStudy** *(影像紀錄)* | R | R | **C / R / U** | R *(需授權)* | 放射人員上傳 X 光、MRI 檢查紀錄與 DICOM 影像連結。 |
| **ServiceRequest** *(運動處方箋)* | R | **C / R / U** | \- | R *(需授權)* | **醫師開立之運動處方箋、復健指示與禁忌事項。** |
| **CarePlan** *(復健計畫)* | R | R | \- | **C / R / U** | 治療師根據醫師處方擬定、執行與調整個人化復健計畫。 |
| **Procedure** *(治療執行)* | R | R | \- | **C / R / U** | 治療師記錄場館內每次執行的具體復健項目與療程。 |
| **Observation** *(量測 / 居家數據)* | **C / R** *(居家回傳)* | R | \- | **C / R / U** *(場館量測)* | 治療師記錄臨床量測（ROM、肌力）；**患者可透過 App 回傳居家自主訓練數據與疼痛指數**。 |

## **6\. 主要FHIR Resource** 

---

| 資源 | 用途 | 例子   |
| :---- | :---- | :---- |
| **Patient** | 患者基本資料 | 姓名、生日、性別、ID、運動項目 (extension) |
| **Practitioner** | 醫護／治療人員資訊 | 骨科醫師、物理治療師的姓名與職稱 |
| **Encounter** | 就診／療程事件 | 一次門診、一次復健療程 |
| **Condition** | 確診的傷病 | 「左膝前十字韌帶二級撕裂」，含受傷部位 (bodySite) 與嚴重度 (severity) |
| **DiagnosticReport** | 診斷報告 | 醫師對 X 光／MRI 的判讀結論與詳細診斷說明 |
| **ImagingStudy** | 影像檢查紀錄 | X 光、MRI 的檢查資訊 |
| **ServiceRequest** | 轉介／醫囑請求 | 「轉介復健，六週內禁止負重深蹲」 |
| **CarePlan** | 復健計畫 | 治療師制定的階段性復健目標與項目 |
| **Procedure** | 已執行的治療 | 某次療程做了徒手治療＋股四頭肌等長收縮訓練 |
| **Observation** | 量測數據 | 膝關節屈曲角度 95°、大腿圍度 |
